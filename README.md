# SmartBus Lite

A full-stack South India bus-booking MVP with natural-language trip search, live seat selection, mock multi-seat bookings, and ticket-level cancellation.

## Planned stack

- Frontend: React, TypeScript, Vite, Tailwind CSS
- Backend: Express, TypeScript, Prisma
- Database: MySQL locally; TiDB-compatible production setup
- Testing: Vitest and Playwright
